# qa_python
Файлы проекта
conftest.py — фикстуры для тестовых данных
main.py — код класса BooksCollector
README.md — список реализованных тестов
test_data.py — файл с тестовыми данными (константами) для использования в фикстурах и тестах.
tests.py — тесты 

В проекте реализованы тесты:
•	тест добавления книг (уже был описан, внесено исправление)
•	тест на проверку длины названия книги
•	тест на установку жанра
•	тест на жанр книги по ее имени
•	тесты на список книг с определённым жанром:
    —	если жанр есть в списке
    —	если жанра нет в списке
•	тест на получение словаря, проверка метода books_genre
•	тесты на книги, подходящие детям:
    —	неподходящая книга по жанру
    —	подходящая книга
•	тест на добавление в избранное
•	тест на удаление из избранного
•	тест на получение списка избранного
